
# 支持功能

1. 支持开启搜索筛选，默认不开启，树节点高亮关键字，开启可搜索后，顶部出现搜索输入框。也支持自定义传入
2. 支持开启单选/多选/禁用节点，默认不开启，支持自定义图标，或者只自定义图标颜色
3. 支持开启拖拽排序，默认不开启，支持设置拓展手柄或选中节点拓展，支持拖拽图标自定义，位置支持设置在左侧或右侧，默认左侧
4. 支持动态设置显示或不显示辅助线，辅助线样式 虚线/实线 默认开启虚线
5. 支持动态设置自节点错位距离，默认一个图标的距离，可以和上面的对其
6. 支持异步数据加载，节点加载子节点数据时，要有loading，支持自定义传入
7. 展开/收起节点的图标支持自定义传入，位置支持设置在左侧或者右侧，默认左侧
8. 节点右侧支持自定义操作（编辑/删除等）
9. 支持鼠标右键打开菜单，菜单列表用户自定义传入
10. 支持默认展开或收起所有节点
11. 支持展开指定节点
12. 支持选中指定节点，选中的是自节点时，相对应的父节点也应该同步展开
13. 支持展开节点收起其他节点，或展开节点不收起其他节点
14. 支持树只读，关闭全部操作（展开收起除外）
15. 支持自定义样式，包括树整体样式，节点间距，节点样式，图标样式，选中节点样式，节点hover样式，支持styles和className设置
16. 支持外部主题适配
17. 默认有缺损页，支持自定义传入
18. 支持节点展开收起的动画或者不设置动画，默认不设置动画
19. 初次加载要有loading，支持自定义

# 要做的优化

1. 要是受控组件
2. 只更新变化的节点，没有变化的不要更新，防止出现大量重新渲染
3. 筛选数据要做防抖优化
4. 支持虚拟滚动
5. 节点的所有都要有回调方法提供给父组件
6. 数据超时，渲染错误 这些错误边界要做好
7. 一定要做到轻量级，高性能，交互顺畅，非常重要

# 注意

要做好组件封装，代码拆分，注释也要写到详细
