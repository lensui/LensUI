# Tree 组件实施计划

## 包与发布结构

- `Tree` 是可独立发布的 npm package，源码、测试和构建配置与原始素材隔离。
- `exports` 同时提供包根入口和 `./tree` 子路径；未来总组件库用 workspace 聚合导出。
- React/ReactDOM 使用 peer dependency，避免应用中打包两份 React。

## 功能阶段

1. 建立严格类型的节点模型和完全受控的展开、选中、搜索 API。
2. 实现展开/选择/禁用/只读、深层选中展开父节点、手风琴模式。
3. 实现防抖筛选与高亮、异步加载/超时/错误回调、初始加载与空状态。
4. 实现拖拽手柄和落点、右键菜单、右侧操作区、图标位置与自定义渲染。
5. 实现辅助线、缩进、CSS 变量主题、细粒度 styles/classNames。
6. 实现固定行高虚拟滚动与 memo 节点，补充错误边界。
7. 用类型检查、单元测试、生产构建和 npm pack 校验发布产物。

## 数据职责

Tree 不在内部复制并持久化业务树。`loadData`、`onDrop` 等事件只报告变化，由父组件更新 `data`。这样避免双数据源，适合服务端状态、撤销/重做和协同编辑。
